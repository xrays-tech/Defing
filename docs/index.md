# Defing 配置中心

**分布式配置文档服务** —— 单二进制，开箱即用。

## 项目简介

Defing 是一个面向**构建与部署场景**的分布式配置中心：把散落在代码、脚本、CI/CD 里的配置参数统一收口，按 **项目 → 分支 → 分组 → 配置项** 组织，修改走 **草稿 → 版本 → 发布 → 通知** 的完整闭环。

核心特性：

| 能力 | 说明 |
|---|---|
| 单二进制 | Rust 实现，无外部依赖，`defing` 一个文件即完整服务 |
| Raft 强一致集群 | 静态成员表一键建群、动态扩容、leader 故障自动切换 |
| 项目 / 分支模型 | 一个项目多分支（dev / test / prod / 自定义），分支间仅值不同 |
| 草稿 → 发布闭环 | 修改不直接生效，保存草稿、校验、发布为不可变版本 |
| 灰度发布 | 按标签 / IP / 百分比灰度，一键转正或下量回滚 |
| 共享库 | 跨项目复用配置项，发布后自动级联到引用它的项目分支 |
| Secret 加密 | 敏感项 AES-256-GCM 信封加密；SDK 数据面恒脱敏，构建脚本渲染端点按令牌授权解密（审计） |
| 三语言 SDK | TypeScript / Go / Python，gRPC 优先 + HTTP/SSE 降级 |
| 项目访问令牌 | Admin UI 管理，每项目独立、可吊销，轮换零中断 |
| 构建脚本取值 | 纯 curl 拉取指定分支配置，直接输出 YAML / JSON / TOML / ENV |
| 内嵌管理台 | `/admin` 全功能 Admin UI（本项目教程即以此演示） |

登录后默认进入「配置管理」：顶部选择项目与分支，左侧导航切换「配置管理 / 共享库 / 审计日志 / 集群节点 / 管理员」。

## 快速上手

1. 启动服务（单机联调）：`defing --dev-single --admin-password <密码> --allow-no-master-key`
2. 浏览器打开 `http://<host>:8384/admin`，用管理员密码登录
3. 创建项目 → 定义结构（组与配置项）→ 发布结构
4. 在草稿页填写各分支的值 → 保存草稿 → 发布版本
5. 应用通过 SDK 或 curl 读取指定分支的配置

👉 从 [快速开始]({{ site.baseurl }}/quickstart/) 开始，或按左侧章节逐篇阅读。
