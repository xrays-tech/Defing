# 09 管理员与审计

## 9.1 角色与账号管理

Defing 有三类管理员，权限自上而下收窄：

| 角色 | 登录方式 | 权限边界 | 审计 operator |
| --- | --- | --- | --- |
| **超级管理员**（部署时创建） | 登录时**用户名留空** | 全部端点：项目增删、访问令牌、账号管理（全局管理员 + 项目管理员）、集群写、快照与主密钥轮换 | `admin` |
| **全局管理员**（GA，由超级管理员创建） | 登录时填用户名 | **全部项目**的配置与**全部共享配置**；不能管理账号、不能集群写、不能创建/删除项目、不能管理项目访问令牌 | `ga:{username}` |
| **项目管理员**（PA，由超级管理员按项目创建） | 登录时填用户名 | **所属项目**的配置；共享配置**只读**；不能管理账号、不能集群写 | `pa:{username}` |

> 用户名规则：GA 与 PA 的用户名**全局唯一且不区分大小写**（如 GA `Alice` 与 PA `alice` 互斥），长度 2-64 位 `[A-Za-z0-9_-]`，且**不可使用保留名 admin**（不区分大小写）。密码最短 6 位。

左侧导航「项目管理员」（**仅超级管理员可见**）：按项目创建 / 改密 / 删除该项目的管理员账号。

### 修改自己的密码（三角色通用）

登录后点击左下角「修改密码」入口（🔒 图标按钮，三种角色均可见）：

- 需验证**当前密码**；新密码至少 6 位且两次输入一致
- 当前密码错误按**主体独立**限速（与登录节流同窗口）：同一主体（超级管理员 / 该 GA 账号 / 该 PA 账号各自计数）600s 窗口内 5 错即 429 `ERR_TOO_MANY_ATTEMPTS`；改密成功时清空计数，其他主体不受影响。防已劫会话 token 时在线暴力猜当前密码
- 修改成功后**该主体的全部旧会话立即失效**，需重新登录。具体范围：**超级管理员**改密只失效其自身会话（`sess/admin*`），**不影响全局管理员与项目管理员**；**全局管理员 / 项目管理员**改密仅失效**该账号自身**的全部会话
- 任何角色都只能修改**自己账号**的密码，不能触碰账号管理面

### 忘记超级管理员密码（免旧密码恢复）

生产环境忘记超级管理员密码、又无有效管理员会话时，在能访问管理面的主机上执行（客户端模式，不启动服务）：

```bash
defing admin reset-password '<新密码≥6位>' --ops-token '<集群 join-token>'
```

- `--ops-token` 的值 = 节点的 `--join-token`（k3s Secret `cluster-token`、compose `DSH_CLUSTER_TOKEN`）；也可用环境变量 `DSH_OPS_TOKEN` / `DSH_CLUSTER_TOKEN`，避免明文进 shell 历史；
- 节点必须配置过 `--join-token` 该恢复通道才可用（未配置恒返回 401）；命中任意节点均可，非 leader 自动转发；
- 成功后与改密一致：超级管理员的全部会话立即下线（**并同时回收全部全局管理员的会话**）、旧密码失效，需用新密码重新登录；审计记录 `admin_password_reset`（operator `ops-token`）；
- **信任边界**：能触发恢复者等价于持有 `--join-token`（可注册 learner 拉取全量日志），请与主密钥同级保管该令牌。

### 项目管理员（PA）

- 一个账号绑定一个项目；一个项目可有多个账号
- PA 可登录 Admin UI 管理**自己项目**的草稿 / 结构 / 发布 / 灰度 / 版本；导航仅显示「配置管理 / 审计日志 / 集群节点」（共享库、访问令牌、管理员入口对 PA 隐藏）
- 共享项**只读**：草稿页「引用共享」下拉可看到共享项及物化值（secret 值恒掩码），但不能创建 / 修改 / 发布 / 删除共享项
- 集群节点**只读**查看（用于配置 SDK 端点池）；不能管理集群、其他项目、账号管理
- 超级管理员可对 PA 账号「改密 / 删除」（删除后其会话立即失效）；PA 忘记密码时由超级管理员重置。**全局管理员忘记密码时同样只能由超级管理员重置**（GA 不能管理任何账号）

## 9.2 审计日志

左侧导航「审计日志」：

![审计日志]({{ site.baseurl }}/assets/images/10-audit.png)

记录全部管理面操作（最近 200 条），列：seq / 时间 / action / 项目·分支 / 版本 / 操作人 / request_id / 明细：

| 字段 | 说明 |
|---|---|
| seq | 审计流水号（单调递增） |
| 时间 | 操作时间 |
| action | login / project_create / structure_publish / publish / gray_publish / token_create / config_reveal 等 |
| 项目 / 分支 | 操作对象 |
| 版本 | 操作产生的版本号（发布 / 灰度等） |
| 操作人 | `admin`（超级管理员）/ `ga:alice`（全局管理员）/ `pa:alice`（项目管理员）/ `data-plane:{令牌名}`（数据面解密）/ `ops-token`（找回通道） |
| request_id | 请求 ID |
| 明细 | 结构化详情（JSON） |

支持按动作类型过滤（如只看 `gray_publish`）。**reveal 明文查看配置**会记录 `config_reveal` 审计 —— 谁解密看过什么都有据可查。

## 9.3 集群节点

「集群节点」视图展示 Raft 集群状态与成员：

- 顶部状态卡：本节点 node id、集群状态、当前 Leader
- 成员表：node_id / HTTP 地址 / gRPC 地址 / 角色（`voter`、`leader`、`learner`），voter 可移除、learner 可「提升为 voter」
- `--dev-single` 单节点模式无集群成员（显示「无集群成员」提示）
- 集群模式（[01 §1.3]({{ site.baseurl }}/01-install/)）下可查看成员，供 SDK 配置端点池
- 全局管理员与项目管理员均可**只读**查看节点端点（表格行尾显示「只读」，用于配置 SDK 连接）；join / promote / remove 等管理操作仍仅限**超级管理员**。

## 9.4 权限被拒时的表现

越权访问由管理面中间件统一拒绝：HTTP **403**，响应体 `code = ERR_FORBIDDEN`、`message = 无权访问该资源`（三种角色共用同一文案）。全局管理员被拒的面包括：`/api/v1/admins*`（账号管理）、`/api/v1/projects/{p}/tokens*`（访问令牌）、`/api/v1/admin/*`（快照、强制下线、主密钥轮换）、`/api/v1/cluster/{promote,remove}`（集群写），以及`POST /api/v1/projects` / `DELETE /api/v1/projects/{p}`（项目增删）。

## 结语

至此你已走完 Defing 的核心使用流程：**部署 → 项目/分支 → 结构 → 草稿发布 → 灰度 → 共享库 → 令牌/SDK → 构建脚本 → 管理审计**。

更多细节可参考仓库 `docs/` 下的设计与部署文档。
