# 06 共享库

共享库存放**跨项目复用的配置项**（扁平 key，无分组）。结构页将配置项标记为「引用共享」后，各分支在草稿页下拉选择引用的共享项，值由共享库物化 —— 共享项更新发布，绑定它的项目分支**自动级联**。

## 6.1 共享库页面

左侧导航「共享库」：

![共享库]({{ site.baseurl }}/assets/images/09-shared.png)

上方表单创建 / 更新共享项，下方列表展示全部共享项（含草稿与已发布状态、被绑定处数）。

## 6.2 创建并发布共享项

1. 填 key（全局唯一，如 `timeout`）、类型、描述、值
2. 点「保存共享草稿」（写入 `shared-draft`）
3. 点「发布共享」→ 发布全部草稿，绑定它的项目分支自动级联生成新版本

列表中的行标识：

| 标识 | 含义 |
|---|---|
| `草稿`（橙） | 已保存但未发布，尚未生效 |
| `v1`（绿） | 已发布版本 |
| `N 处`（蓝） | 被多少个项目分支绑定（悬浮展示 项目/分支/组/配置项） |
| 表单未保存 / N 个共享草稿未发布 | 顶部状态徽章：有多少没保存、多少存了没发 |

### 6.2.1 编辑已有共享项

列表每行有「编辑」按钮（草稿行载入草稿值；已发布行载入发布值，保存后成为新草稿）：

1. 点「编辑」→ 弹出模态窗体，载入该共享项（key、类型、标记、描述、值）
2. 在弹窗中修改后点「保存共享草稿」→ 弹窗关闭，列表出现/更新对应草稿行
3. 点「发布共享」→ 全部草稿发布，绑定它的项目分支自动级联

注意：

- **key 不可修改**（key 是全局唯一标识与绑定锚点；需要新 key 请新建后另行迁移绑定）
- **secret 项**：值框留空 = **保留当前密文**——只改描述 / required 无需重输密钥；输入新值即更新
- **类型 / secret 变更**：若该共享项已被引用，保存前会弹确认（发布后绑定它的分支绑定将因类型失配被丢弃，需重新选择）
- 编辑被引用项后发布，会自动级联所有绑定它的项目分支（与新建发布同一语义）

## 6.3 项目引用共享项

在项目「结构」页给配置项勾选「引用共享」（类型列保留真实类型，作为分支下拉的类型约束）→ 发布结构后，各分支在「草稿」页为该配置项**下拉选择**引用的共享项：

![草稿页引用共享]({{ site.baseurl }}/assets/images/03-draft.png)

- 引用共享项在草稿页显示「引用共享」徽章 + 下拉 + 物化值，**不可写本地值**（值由共享库物化）
- 不同分支可引用**不同**共享项（如 dev 引 `dev-timeout`、prod 引 `prod-timeout`）
- 共享项 `timeout` 发布 v2 后，所有**绑定它**的项目分支自动产生 shared_cascade 版本（未绑定的分支不受影响）
- 删除共享项时若仍被分支绑定会被拒绝（需先在相关分支解除绑定）

## 6.4 共享项类型与 secret

- 支持与配置项相同的类型（string / int / float / bool / json / array / secret）
- **secret 共享项**需要主密钥；SDK 快照恒脱敏（`***`），渲染端点 `/config` 对项目令牌请求解密返回（与配置项 secret 一致，见 [08 §8.4]({{ site.baseurl }}/08-curl/)）
- 描述字段（≤200 字节）仅作助记，不进入渲染输出
