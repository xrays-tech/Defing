灰度规则

按客户端实例哈希分桶；标签 / CIDR / 百分比任一命中即进入灰度。

以当前分支草稿生成灰度快照；命中规则的客户端读灰度快照，其余读稳定版。发布前请先保存草稿。

结构以「组 → 配置项」两级定义 key、类型与约束（required / secret）。发布结构将推进全部分支的版本；结构中已不存在的组 / 配置项，其未发布的草稿值会在发布后自动清理，已发布版本不受影响。
